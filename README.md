# Selenium E2E & RestAssured API Automation Framework

## 📌 Overview
An end-to-end automation framework combining UI browser testing and backend REST API automation. Built with Java, TestNG, Selenium WebDriver, and RestAssured, this framework validates complete UI user flows as well as full API CRUD operations (`GET`, `POST`, `PUT`, `DELETE`).

## 🛠️ Tech Stack
* **Language:** Java
* **API Testing:** REST Assured
* **UI Automation:** Selenium WebDriver
* **Test Runner / Assertions:** TestNG
* **Build Management:** Maven
* **Data Handling:** Apache POI (Excel Data-Driven Testing)
* **Version Control:** Git & GitHub

## 🧪 Test Coverage
* **API Suite:** Automated testing for REST endpoints verifying response codes (`200 OK`, `201 Created`, `204 No Content`) and JSON payload assertions.
* **UI E2E Suite:** Automated web application testing, login authentication, dynamic UI interactions, and product report generation (`SwagLabs_Product_Report.xlsx`).
